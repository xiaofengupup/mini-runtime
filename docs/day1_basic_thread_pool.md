# 基础线程池 ThreadPool

## 今日目标

实现一个**固定线程数的基础线程池**，支持：

- 提交 `void()` 任务
- 多个工作线程并发执行
- 多个生产者并发提交
- 条件变量等待和唤醒
- 优雅停止
- 析构时自动回收线程
- 支持重复调用 `Stop()`
- 停止后拒绝新任务

## 核心并发模型

基础线程池使用**生产者-消费者模型**：

- 调用 `Submit` 的线程是生产者；
- 工作线程是消费者；
- `std::queue` 是共享任务队列；
- `std::mutex` 保护任务队列和停止状态；
- `conditional_variable` 用于工作线程休眠和唤醒；

## WorkerLoop 流程

1. 获取任务队列锁；
2. 等待任务到达或线程池停止；
3. 如果线程池停止且任务队列为空，则直接退出；
4. 否则，从队列中取出任务
5. 释放任务队列锁；
6. 执行任务；
7. 返回循环

## 关键设计

### 任务在锁外执行

任务运行时间不可控，持锁执行会阻塞其它提交线程和工作线程；

### 停止时继续处理已有任务

退出条件是：
```cpp
m_stopping && tasks_.empty()
```
仅有 m_stopping 为 true 时不能立即退出，因为队列中可能还有任务。

### Stop() 可以重复调用

使用 `std::once_flag` 和 `std::call_once` 保证停止及 `join` 操作只执行一次。

## 当前限制

- 任务必须是 `void()` 类型；
- 不支持返回值；
- 不支持通过 `future` 传播异常；
- 不支持任务取消；
- 任务队列没有容量限制；
- 所有工作线程共享一个全局队列；
- 不支持从工作线程内销毁线程池；

这些功能将在后续阶段扩展。
